# Zibin Zhao: an open collection

Canonical product definition for the September 7, 2026 local redesign. This spatial field supersedes the nocturnal desk, illustrated portfolio, three-room hero, and vertical collection designs.

## Purpose

A personal world that visitors explore through objects and curiosity. Research, software, music, a miniature railway, and personal traces occupy one shared space. The homepage has no prescribed section sequence: visitors choose an object or use the Index to reach the material that interests them.

## Experience

The homepage is an actual interactive 3D field with eight linked artifacts. Dragging changes the angle of the whole field; another-angle, reset, and motion controls support exploration. Semantic HTML labels follow projected object positions on the desktop field and remain real links. The eight destinations are Research, Projects, Singularity, Medit, About, Prompts, CV, and Contact.

Interior routes present their content as a floating reading sheet over a fixed 3D background. They retain ordinary document scrolling and a link back to the field. A native Index disclosure is available at every viewport size, alongside the language switch. This gives direct access to all seven portfolio pages without requiring spatial interaction.

## Observable checks

- The supported WebGL path renders the field, positions linked labels, responds to dragging, and provides another-angle, reset, and pause/resume controls.
- Reduced motion starts the scene paused; hidden or offscreen scenes suspend continuous rendering. WebGL failure preserves a visual fallback and functional HTML content.
- Index navigation, language paths, keyboard focus, skip navigation, and disclosure content work without JavaScript where applicable.
- Mobile and 320 px layouts, enlarged text, and landscape resizing keep content readable, links reachable, and the document free of horizontal overflow.
- Reading sheets retain project filters, exact copying and manual recovery, prompt hash navigation, downloads, 404 recovery, canonical metadata, and the fourteen-URL sitemap.
- Check the rendered desktop and mobile experience, then run formatting, lint, Astro checks, unit tests, the production build, and browser regressions. Record actual results separately from these acceptance criteria.
