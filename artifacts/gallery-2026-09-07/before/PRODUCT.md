# Zibin Zhao: personal website

Canonical definition for the September 2026 rebuild, revised after owner feedback. The owner authorized a complete local redesign, rejected the first draft as too template-like, and explicitly chose to integrate the nocturnal character throughout the site rather than retain a separate Night page. This supersedes the illustrated portfolio draft and the earlier Stitch specifications. Publication remains separate.

## Purpose and audience

A personal introduction balancing research and product work. Visitors should understand who Zibin is, inspect actual work, and find a direct way to get in touch. The site should read like a person's own page, using direct language and concrete work rather than a promotional landing-page formula.

## Scope

Seven bilingual destinations: Home, Research, Projects, About, CV, Contact, and Prompts. Preserve their English public routes, the romanized name, verified research records, source links, original prompt bodies, explicit Chinese routes, and the embedded Medit and Singularity applications. Remove the standalone Night route and generated landscape. Use native scrolling and curated project data.

## Acceptance

Readable at 320 px and 200% text size. Keyboard and no-JavaScript navigation. Persistent locale through URL paths. Explicit project demos and source links. Journal articles distinguished from preprints. Recoverable clipboard failures. Consistent metadata and a sitemap containing only the fourteen current portfolio URLs. Actual desktop/mobile visual review, static checks, unit tests, build, and browser flows. No oversized promotional hero, repeated card placeholders, generic slogans, or detached atmosphere page.

## Boundaries

No invented results, credentials, metrics, anecdotes, or testimonials. No analytics, accounts, backend, production deployment, external messages, or broad rewrites of the separately built applications. The first draft is archived for comparison; this revision is the current local source.
